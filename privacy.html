Политика конфиденциальности

Приложение «MetalGear Аналитик». Обновлено 10.09.2026.

Что это

Личное настольное приложение владельца YouTube-канала MetalGear_Guitars. Устанавливается на его компьютер и используется только им.

Какие данные

Статистика собственного канала: просмотры, подписчики, показы, CTR, удержание, источники трафика, метаданные видео. Плюс токен доступа Google. Персональные данные зрителей не собираются.

Как используются

Только для показа аналитики владельцу канала. Не продаются, не передаются третьим лицам, не используются в рекламе и для обучения моделей.

Где хранятся

Только на компьютере пользователя: база SQLite в каталоге приложения, токен — в защищённом хранилище ОС. Своих серверов у приложения нет.

Разрешения

YouTube Data API, YouTube Analytics API и YouTube Reporting API в режиме только для чтения. Приложение ничего не меняет и не удаляет на канале.

Отзыв доступа

В любой момент на myaccount.google.com/permissions. Чтобы стереть собранные данные, удалите каталог приложения.
