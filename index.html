MetalGear Аналитик

Настольное приложение для анализа статистики YouTube-канала MetalGear_Guitars. Работает локально на компьютере владельца канала, читает данные через официальные API YouTube (только чтение) и хранит их в локальной базе.

Приложение личное: доступ к нему есть только у владельца канала. Данные никуда не передаются и не публикуются.
